# 🌊 Topografie: Wateren van Nederland (Topo-Kids)

Een interactieve, kindvriendelijke webapplicatie waarmee kinderen op een speelse manier de **17 wateren van Nederland** leren (Romeinse cijfers I t/m XVII).

## ✨ Functies
- 🔍 **Oefenen & Verkennen**: Klik op een nummer op de interactieve D3.js kaart om de naam, uitspraak en informatie over het water te horen.
- 🎯 **Aanwijzen (Quiz)**: De app vraagt waar een specifiek water ligt en de leerling moet het juiste Romeinse cijfer op de kaart aanwijzen.
- ✏️ **Spelling Kampioen**: Oefen de spelling van het water met interactieve lettertegels of door de naam zelf te typen.
- 🔊 **Spraakondersteuning**: Web Audio geluidseffecten en Nederlandse uitspraak via SpeechSynthesis.
- 📱 **Volledig Responsive**: Werkt op mobiel, tablet, Chromebooks en desktop (inclusief soepel zoomen en pannen).

## 🚀 Lokaal draaien
Open simpelweg `index.html` in een willekeurige browser, of start een lokale webserver:
```bash
npx serve .
```

## 🌐 Online publiceren via Vercel
Deze webapp is direct geoptimaliseerd voor deployment op [Vercel](https://vercel.com):
```bash
npx vercel
```
Voor productie deployment:
```bash
npx vercel --prod
```
